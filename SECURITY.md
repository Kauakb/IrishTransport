# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/Kauakb/IrishTransport/security/advisories/new)

Include what you found, how to reproduce it, and the possible impact. You'll get a reply as soon as possible.

## Supported versions

Only the latest version on the `main` branch is supported.
